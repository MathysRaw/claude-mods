# token-meter

Compteur de tokens permanent au-dessus de la zone de saisie :
dernier tour · total de la discussion · % de contexte · coût · limites 5h / 7j.

- `/tokens` : tableau détaillé (dernier tour, discussion, cumul toutes discussions)
- `/tokens-toggle` : afficher / masquer le bandeau

## Installation

```
/plugin install token-meter --marketplace MathysRaw/claude-mods
```
